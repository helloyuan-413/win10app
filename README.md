# Win10 模拟桌面 · V1.2.2

> 在手机上运行一个完整的 Windows 10 风格桌面，随时随地访问，无需电脑。

---

## 📖 应用简介

**Win10 模拟桌面** 是一款运行在 Android 设备上的轻量级网页桌面应用。它通过内网穿透技术，让你可以在一台手机（或任何能访问公网的设备）上，打开一个完整还原的 Windows 10 风格操作界面——包括浏览器、计算器、资源管理器、记事本、任务管理器等常用组件。

应用本身不占用大量存储，核心逻辑由后端提供，通过安全隧道实时同步。安装即用，无需配置。

---

## ✨ 主要特性

- 🖥️ **还原度高** — 仿 Windows 10 桌面布局，图标、任务栏、开始菜单齐全
- ⚡ **即开即用** — 安装后自动连接服务端，无需手动输入任何地址
- 🌐 **跨网络可用** — 支持 Wi-Fi、移动数据，无论在家还是在外都能访问
- 🔄 **地址自动更新** — 后端地址变化时，应用会自动获取最新地址并切换，无需重新安装
- 🛡️ **断线保护** — 连接异常时主动提示，避免误操作导致内容丢失
- 📦 **轻量体积** — APK 仅约 11 MB，低配设备也能流畅运行

## 🛠️ 技术栈

- **后端**：Python 标准库（HTTP Server + SQLite）
- **内网穿透**：Cloudflare Tunnel (`cloudflared`)
- **地址广播**：ntfy.sh
- **前端**：纯 HTML + CSS + JavaScript
